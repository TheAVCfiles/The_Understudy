# Hackathon Compliance Notes

## Track

Preferred track: Replit.

## v0.1 status

This v0.1 repository is a clean-room public scaffold. It proves the Director -> Producer -> Evaluator agent loop in deterministic demo mode and is intentionally safe to publish.

It is not yet submission-complete. The final hackathon submission must add a compliant Gemini / Google Cloud runtime path and a Replit deployment URL.

## Required runtime proof for final submission

The final submission must demonstrate:

- Google Cloud / Gemini usage at runtime;
- Replit deployment on a `replit.app` or `replit.dev` domain for the Replit partner track;
- source code that imports and actually calls the required Google Cloud / Gemini package or endpoint;
- source code and instructions sufficient for judges to run the project;
- public open-source license file visible at the repository root;
- hosted project URL;
- public English demo video under 3 minutes.

## Excluded materials

This project must not include proprietary Global AVC Systems, StagePort, DeCrypt, MythOS, client, legal, evidence, investor, or patent-sensitive materials.

## AI restrictions

Only Google Cloud AI tools and permitted partner built-in AI features may be used for submitted AI/agent functionality. No OpenAI, Anthropic, AWS AI, Microsoft AI, or other non-permitted AI APIs should be used in the submitted runtime path.

Deterministic demo fallback is allowed for local resilience, but the submitted project must visibly demonstrate the Gemini / Google Cloud path.
